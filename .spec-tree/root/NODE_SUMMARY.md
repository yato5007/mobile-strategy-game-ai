# Root Node Summary

## Identity
Root node of the Recursive Spec Kit tree for the Mobile Multiplayer Strategic Game.

## Game Design (Emerged via Spec Kit)
**Lane-control simultaneous deployment strategy game.**
- Players assign cards/tokens to lanes simultaneously each round.
- Simultaneous reveal, lane resolution, VP awarded.
- Most VP after 10–12 rounds wins.
- Supports FFA (4 players) and 2v2 team modes.
- Fixed rounds, no early end.
- Comeback bonuses for trailing players.

## Key Decisions Made
1. Game format: lane-control simultaneous strategy (not area-control, not speed-based).
2. Win condition: most VP after fixed rounds.
3. Active play enforced: must assign cards every round.
4. Comeback: last-place bonuses, later rounds higher stakes.
5. Anti-dominant strategy: rotating objectives, hidden info, bluffing.
