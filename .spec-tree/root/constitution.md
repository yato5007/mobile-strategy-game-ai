# Root Node Constitution

## Identity
This is the root node of the Recursive Spec Kit tree for the Mobile Multiplayer Strategic Game project.

## Mission
Build a complete, strategic, multiplayer mobile game where decisions matter, matches are under 30 minutes, and every player has a path to victory until the end. The game design must emerge through the Spec Kit process, not be imposed.

## Scope
- Full project lifecycle from game design through implementation to final AI handoff package.
- All systems: game logic, UI, multiplayer, bots, localization, testing, balance, documentation.
- Arabic-first, English-ready, Expo React Native, Android + iOS.

## Out of Scope
- Real-time reflexes / speed-based mechanics.
- Single-player-only design.
- Non-strategic shallow score races.
- Heavy management or excessive complexity.

## Constraints
1. Must be strategic (not reflex/speed).
2. Must support multiplayer (4 players, 2v2, FFA).
3. No turn waiting — simultaneous planning or action.
4. Easy to understand, quick to get into.
5. Match must end within 30 minutes.
6. A losing player must be able to come back.
7. Active play must matter throughout.
8. Clear win condition.
9. Match must stay open until the end.
10. Lead must be able to shift repeatedly.
11. Support Arabic/English, RTL/LTR, Android/iOS.
12. Bot opponents with difficulty levels (Easy, Normal, Hard, Expert) and strategic styles.
13. No dominant strategy — balance must be tested.
14. Spec Kit determines the game format, not direct design.

## Parent
None. This is the root.

## Child Branches
Will be derived after root Spec Kit clarifies what the game is.
