# Skill: Asset Manifest Update

Use this skill whenever art, audio, animation, or visual feedback changes.

Steps:
1. Update ASSET_MANIFEST.md.
2. Identify placeholder vs final.
3. Document source or rights.
4. Link asset to gameplay/UI purpose.
5. Ensure no unclear copyrighted asset is used.
6. Update AI_HANDOFF_MANUAL.md if needed.
