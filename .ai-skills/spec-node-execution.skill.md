# Skill: Spec Node Execution

Use this skill when executing one Recursive Spec Kit node.

Steps:
1. Read parent artifacts.
2. Read GAME_CONSTRAINTS.md.
3. Read SPEC_TREE_RULES.md.
4. Create or update node artifacts.
5. Ensure constitution/spec/clarification/plan/tasks/analysis/checklist exist.
6. Add NODE_SUMMARY.md.
7. Add integration notes.
8. Mark state in SPEC_TREE_STATUS.md.
9. Update progress and trace.
10. Checkpoint.
