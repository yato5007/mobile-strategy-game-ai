# Asset Manifest

This file tracks all art, audio, motion, and visual game-feel assets.

## Rules

- No unclear copyrighted assets.
- Placeholder assets are allowed during development.
- Every asset must document whether it is placeholder or final.
- Every asset must support gameplay clarity.
- Art, audio, and motion must not distract from strategic decisions.

## Required Asset Categories

1. App icon and splash direction.
2. Arabic-first UI visual identity.
3. Game board / tactical space presentation.
4. Player markers, units, tokens, or symbolic pieces as selected by Spec Kit.
5. Action/order icons.
6. Result and feedback icons.
7. Sound effects for important actions.
8. Motion and transition rules.
9. Win/loss feedback.
10. Endgame tension feedback.

## Placeholder Rule

If final assets cannot be produced now:

1. Use legal placeholders.
2. Document them here.
3. Explain how to replace them later.
4. Ensure the game remains playable and understandable.
